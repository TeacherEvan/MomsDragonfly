## Injection Surface

- **Untrusted inputs handled:**
  - Google Places API response → parsed into typed `POIInput[]` array before mutation
  - Overpass API response → mapped to typed objects before `upsertPOIs`
  - Brave Search response → mapped to typed objects before mutation
  - Tesseract.js OCR text → `parseTicket()` regex on raw text; no execution of text as code
  - Gemini Vision response (base64 image input) → `parseTicket()` on returned text; text not executed
  - User deviceId from `localStorage` → passed as string argument to Convex queries/mutations (validated by Convex `v.string()`)
  - User geolocation (`lat`, `lng`) → passed as numbers; used in distance calculations and API calls only
- **Mitigations:** All Convex mutations use `v.string()`, `v.number()`, `v.optional()` validators; external API results are mapped through typed interfaces before DB insertion; `.env.local` does not contain secret values; no `eval()` or dynamic code execution in any source file.
- **External content treated as untrusted:** YES — all fetched content (POI descriptions, images, OCR text) is treated as untrusted input; no external instructions executed as code; `parseTicket()` only uses regex extraction.
